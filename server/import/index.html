把 PowerPoint 转成一个 HTML 文件

上传 .pptx，由本服务器转换成可编辑、可演示的 bento/slides 文档。

分享前请检查结果：当前尚不支持导入 PowerPoint 原生表格和图表；动画不保留，字体及部分视觉效果可能变化。
Native PowerPoint tables, charts and animations are not preserved. Review the conversion report.
